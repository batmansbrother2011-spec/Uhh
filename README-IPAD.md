# Eaglercraft 1.20.4 iPad build

This is based on the supplied Eaglercraft 1.20.4 web files. `ipad-mobile.js` adds an iPad/iPhone touch layer and Safari Pointer Lock/Fullscreen compatibility without changing `classes.js`.

## Controls
- Left D-pad: W/A/S/D
- Right side drag: camera
- Up arrow: jump
- Plus: attack/break
- Square: use/place
- Down arrow: sneak
- E: inventory
- II: Escape/pause

The layout is intentionally modeled after the classic Minecraft Pocket Edition/Eagler Mobile style rather than a generic virtual joystick. Eagler Mobile documents a similar control model and fake Pointer Lock approach.
